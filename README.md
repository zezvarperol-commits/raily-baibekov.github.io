# School Terminal 73

Сайт МБОУ «Школа №73» г.о. Самара в стиле терминала. Учебный проект по HTML, CSS и JavaScript.

## Разделы

- **Главная** — приветствие и 4 профиля обучения (Соц-эконом, Био-Хим, Технический, Психологический)
- **Расписание** — заглушка «Временные неполадки»
- **ВПР** — что это, кто участвует, как проходят, как подготовиться
- **АСУ РСО** — описание системы, вход, где взять логин
- **Администрация** — карточки руководства с местом под фото
- **История** — история школы с 1960 года
- **Контакты** — адрес, телефон, email, Яндекс.Карта

## Интерактив

- **Ватермарка-конвейер** — надпись «Байбеков» бесконечно едет по фону под углом
- **Подпись автора** — перетаскивается мышкой. Shift+клик включает физику (падение, отскоки). Двойной клик — сброс в угол
- **Виртуальный помощник** — в правом нижнем углу, рассказывает о любом элементе в техническом плане. Эмоции: `>_`, `^_^`, `o_o`, `O_O`, `T_T`, `@_@`
- **Убегающие кнопки** — кнопки и карточки смещаются от курсора
- **Автоскрытие навигации** — панель уезжает за экран через 3 секунды бездействия
